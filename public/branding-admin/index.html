4. Публикация

Публикация отправляет POST на admin URL: { config: { version, logoUrl, iconUrl, faviconUrl, brandName, themeCss, updatedAt } }. Основной сайт/клиент подхватят конфиг при следующем запросе (кеш/опрос в branding.js). Реальная проверка прав — на бэкенде.

5. Администраторы (только GGSHNIKK)

Назначенные здесь пользователи получают полные админ-права (удаление, брендинг и т.д.). Управление доступно только суперадмину GGSHNIKK. Требуется действующая сессия GGSHNIKK (или заголовок авторизации выше).
